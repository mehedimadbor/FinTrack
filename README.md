# FinTrack — Personal Money Management

FinTrack is a modern, responsive and user-friendly personal finance web application designed to help you manage your daily money, track transactions, monitor expenses, manage loans, plan savings and understand your financial situation from one dashboard.

«Plan your money. Track your spending. Build better financial habits.»

---

✨ Features

📊 Financial Dashboard

- Total balance overview
- Total income
- Total expenses
- Total loans
- Total savings
- Today's financial summary
- Monthly financial summary
- Weekly expense comparison
- Last 6 months income & expense chart
- Recent transactions

- Add income/deposit
- Add expenses

- Track income sources

- Search transaction history

💳 Loan Management

- Track money you have lent

🎯 Budget & Savings

🔄 Recurring Transactions

Set recurring financial entries such as:

- Monthly salary
- House rent
- Bills
- Regular expenses
- Other recurring income or expenses

Recurring entries can be automatically added based on the selected date.

🤖 AI Finance Assistant

FinTrack includes a built-in AI-style finance assistant that can understand simple financial commands and questions.

Examples:

How much did I spend this month?

What is my current balance?

How much does Rahim owe me?

I spent 500 taka on food.

I gave Rahim a loan of 1000 taka.

Show my transaction history.

The assistant can also help with transaction entry, history lookup and removing the latest entry.

💾 Data Storage

FinTrack uses browser-based local storage for its core data.

This means financial information can be stored locally in the user's browser without requiring a traditional database for the core functionality.

«Clearing browser/site data may remove locally stored application data. Users should use available backup functionality where appropriate.»

---

🔒 Privacy

FinTrack is designed with a privacy-focused approach.

Financial information used by the core application is handled on the user's device through browser storage. Features that depend on external services may have their own data-handling requirements.
